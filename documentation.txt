● What is the intended purpose of your application?
    My application is a digital bullet journal, which is a task management system that
    is used to track tasks, organize schedules, take notes, and reflect on notes taken.
    Traditionally the system was used for rapid note taking and thought organization for
    people with scattered thoughts or ADHD.

● What work has been completed for this milestone?
    I have created a simple maker page, that allows users to view all of their collections, 
    all of their entries, and all the relevant information. Forms exist for creating entries
    and collections, and react updates the entries and collections in the server using router
    and controllers

● How are you using React?

    I am using react to create multiple components: Container, Entry, EntryList, ContainerList, ContainerForm, EntryForm.
    These components are currently used on a "maker" page, with some appearing several times. I want to add a component

● What data are you storing in MongoDB?
    ○ What data do you still need to store?

    I am storing "Entry" and "Collection" models, as well as an "Account". Entries need a type(task, event, note), content,
    color(hex), the id of the parentContainer, and the id of the account owner. Containers need a name, color, and id of the
    account.
